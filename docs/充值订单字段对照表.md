# 充值订单 Excel 导出字段映射核对表

本表以 `data_templates/充值订单/导出数据列表 (3).xlsx` 的首行列名为准，供人工编辑核对。请直接修改“本地字段 / API 字段”“使用方式”“转换规则”和“核对状态”列，并保留未确认项的说明。

刷新方式：系统按盘口业务时区导出一个完整自然日的 Excel，解析后只缓存本表列出的字段。订单明细、支付渠道汇总和图表都只查询本地缓存，不在页面加载时请求远端。

使用方式说明：**直接展示**指页面展示该字段值（金额、日期仅格式化）；**间接展示**指字典映射或聚合后的结果；**间接引用**指去重、筛选、分组或计算时使用；**不缓存**指不会保存或经 API 返回。
