# 充值订单展示名与远端响应字段对照表

这是一份可人工编辑的核对表。当前实现按“初始理解”读取并缓存远端响应字段；请直接修改“展示名称”“响应字段”“规则/备注”和“核对状态”列，再反馈修改结果以便同步代码与数据库字段。

约定：订单明细和渠道汇总页只读取本地缓存；不会在页面加载时请求远端。缓存不保存账号、IP、昵称、附件或原始回调内容。

使用方式说明：

- **直接展示**：页面展示该字段本身；日期、金额等仅做格式化，不改变业务含义。
- **间接展示**：先经过字典转换、聚合或计算，再展示转换后的名称或指标。
- **间接引用**：用于筛选、排序、分组、去重或计算，但页面不展示原始字段值。
- **API 返回、页面未展示**：明细接口仍返回该字段，但当前页面组件没有使用或展示。
- **未引用**：当前充值订单明细和支付渠道汇总均未使用。

## 明确不缓存的远端字段

下列字段不属于当前明细、汇总或刷新逻辑，且可能涉及无关个人数据、账户数据或远端回调内容，因此不会保存到本地：`account`、`ip`、`nick_name`、`from`、`attach`、`out_create_code`、`out_notify_code`、`pro_id`、`pro_order_id`、`charge_id`、`fill_order`、`user_status`、`pay_type`。

如其中某个字段确实是后续展示或统计所需，请将其增加到上方表格并写明展示名称、业务含义、是否可持久化和计算规则。
