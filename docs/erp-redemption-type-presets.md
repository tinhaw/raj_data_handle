# 标签目录与分类型组合预设

标签同步仍由统一远端账号服务写入 `remote_account_tag_snapshots`。打开弹窗、切换盘口和切换兑换码类型均读取已保存标签，不自动访问远端。同步失败保留已加载标签。

组合预设按账号与兑换码类型保存，每种类型一套，包含用户类型、标签、名称及金额档位。日充值和近七天互不覆盖。切换类型会加载对应已保存预设，未保存的编辑不会跨类型保留；无预设时使用该类型默认档位。

新增 Alembic `0042`：原预设主键扩展为 `(account_id, redemption_type)`。旧预设归为 `SEVEN_DAY_DEPOSIT`，不改原内容；日充值使用 `PREVIOUS_DAY_DEPOSIT`。出现日充值预设时禁止有损 downgrade。迁移必须先于新版应用执行；旧应用不兼容复合主键，迁移与上线之间必须停写，不能混跑。此次本地修改不执行迁移或部署。

GET/PUT 统一账号预设接口支持 `redemption_type` 查询参数，省略时仍为近七天。兼容界面传入 `redemptionType`，Java 适配层透传并保留统一会话及权限检查。历史账号删除迁移同时检查并迁移两种类型，冲突不覆盖。

验证覆盖：标签新会话读回、两类预设隔离、账号迁移保留两类预设、旧数据迁移保留、禁止有损降级、Java 类型参数透传及前端加载契约。没有远端业务写入。
