# 兑换码任务独立详情页

已于 2026-11-13 发布生产。本次没有数据库结构变更，结构保持 0061。发布记录见 `erp-redemption-task-detail-production-20261113.md`。

## 页面与入口

任务列表的“查看任务”和“处理待创建”进入 `/erp/redemption/:taskId`。路径参数为数据库任务 ID，页头展示业务任务编号。`batch` 查询参数记录当前盘口；返回列表携带页码、每页数量和表格滚动位置。

详情使用任务专用只读接口 `GET /redemption-campaigns/tasks/{taskId}`，只加载本任务的盘口和配置。保留已有创建、重试、核验、发布及下载处理器，不在打开详情时提交远端业务写入。

布局沿用现有深浅主题、语义色与 Element Plus 组件：

- 页头：任务编号、返回、刷新、删除进度与整任务删除。
- 盘口标签页；紧凑概览展示类型、日期、配置进度及发布状态。
- 完整任务参数默认折叠，避免挤占配置列表。
- 表格展示配置 ID、兑换码、兑换日、档位、任务奖励、领取上限、状态及操作。展开行显示完整生效时间、备注、标签和错误信息。
- 可按兑换码/配置 ID/档位搜索、日期及状态筛选。更换筛选或盘口清除选择，避免误删隐藏选择。
- 桌面固定表头、选择列和操作列；窄屏取消固定操作列并支持表格横向滚动，参数改为单列。

## 单条及勾选删除

单条“删除配置”、勾选后的“删除已选”和“删除整任务配置”共用预检及明确确认流程。查看进度时没有历史记录则展示空态，不自动建立删除计划。

`POST /tasks/{taskId}/deletion/preview` 可接收 `issueIds`。服务端校验非空、数量上限、每项所属任务，按远端身份去重，并在原任务范围快照中保存选择标志。浏览器不能直接指定远端配置身份或跳过原有账号能力校验。

恢复请求使用 `resumeJobId` 引用上一份冻结范围，不重新从界面收集全任务配置。空清单、其他任务 ID、非最新恢复计划、变化的任务范围及正在执行的不同范围均拒绝。已有 JSON 快照缺少选择标志时按原整任务范围处理。

预检完成后列出配置、共享任务、存在性、核对时间和执行状态；勾选影响确认、输入业务任务编号后才允许提交。原有未知结果防重放、审计、共享引用、库存保护保持有效。取消或离开只停止后续调度，已提交请求仍由原流程核对。
