# 远端后台发布后回到本系统下载

## 使用流程

1. 在已完成配置创建的任务中选择“选择发布方式 → 远端后台发布”。多盘口任务会分别列出盘口、远端账号和发布环境。
2. 通过“打开远端管理后台”进入对应盘口，使用对应账号发布该批次配置。
3. 远端执行完成后，从远端发布任务列表复制该次发布任务 ID，回到本系统填写。这里需要的是发布任务 ID，不是本地任务编号或兑换配置 ID。
4. 点击“核验并下载兑换码”。系统逐盘口核验并下载，结果持续显示在各盘口下。全部入库后，在任务列表下载多 Sheet Excel。
5. 某盘口未完成或下载失败时可以重试；已入库的盘口跳过，不重复下载。

选择该选项或打开后台链接本身不会变更任务状态。尚未完成的远端定时发布不能提前下载；关闭页面后仍可从待发布任务重新进入。关联成功但未下载完的任务，可从原有任务详情的核验和下载入口继续。

## 实现与边界

- 新增兼容 API `POST /api/v1/redemption-campaigns/batches/{batchId}/external-publication`，输入 `rowVersion` 与 `remotePublishTaskId`。
- 仅接受配置全部创建、配置 ID 与兑换组标识完整、没有发布占位的 `READY_TO_PUBLISH` 批次。已进入缺失配置重建流程的批次不在本次范围内。
- 复用统一远端账号与下载能力校验，读取发布任务和配置列表；不新增账号、凭据或会话体系，不调用远端发布、创建或撤销接口。
- 精确核验操作者指定的远端任务 ID、环境、配置类型、完成状态，以及本批次每条配置 ID、兑换组标识、兑换码数量。当前远端列表契约不提供发布任务包含的完整配置清单，因此仍须由操作者选择对应发布任务；不按“最新任务”推测关联。
- 核验前后检查批次版本、状态、账号与配置快照，避免将过期核验结果用于变化后的批次。成功关联写入 `remotePublishMode=EXTERNAL`、远端任务 ID 与独立审计事件；`publishedAt` 记录本系统确认时间，不冒充远端实际发布时间。
- 后续下载继续逐次执行既有远端完成及配置匹配检查、代码数量/内容校验和本地入库，完成后才允许完整 Excel 导出。
- 无新增字段或数据库迁移。回退应用不删除既有关联或已下载兑换码；旧版本仍使用已保存的远端发布任务 ID 核验下载，可能无法显示新的发布方式文案。

## 本地验证（2026-09-27）

- Java 统一账号和下载链路测试 39 项通过，其中新增 15 项外部发布关联、失败边界及权限输入测试；包含成功入库、未知/未完成/失败、配置缺失/不匹配、列表错误、版本及配置竞态、发布占位、跨盘口和重复提交。
- Python 既有远端核验、兼容执行器与前端契约测试 38 项通过；前端状态测试 5 项通过。
- ERP 独立前端及主项目 `apps/web` 的类型检查和生产构建通过（构建保留现有大包警告）。既有兑换码 HTTP 流程及兼容模式上下文回归通过。
- 浏览器本地模拟验证：两个盘口分别输入发布任务 ID；空输入阻止请求；一个盘口成功、一个未完成时分别展示结果；补齐第二盘口后出现完整 Excel 下载入口。记录的调用不含远端创建、发布或撤销，已完成盘口只下载一次。
- 本次没有连接生产 ECS，也没有针对真实账号执行发布、核验或下载。生产上线仍需单独确认环境、备份/回退方案和窗口，并使用项目发布脚本。
