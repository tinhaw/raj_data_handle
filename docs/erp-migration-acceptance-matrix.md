# ERP 迁移与融合验收矩阵

基线日期：2026-08-27

对照来源：云端 `erp.aiggtj.com` 只读巡检及本地最新 `raj-ads-manage` 源码。
目标系统：`raj_data_handle`，沿用一套登录体系和一套 `SourceConfig + RemoteAccount` 盘口/账号主数据。

状态定义：

- **功能等价**：页面、API、权限、数据、导入导出和状态机与线上版本逐项对比通过。
- **融合等价**：因统一身份或统一远端账号边界而有意使用主系统页面，业务能力和数据归属等价。
- **部分等价**：已有页面或服务，但尚未完成线上行为和视觉差异验收。
- **代码就绪/执行禁用**：远端协议和内部执行代码已迁移，但没有可从页面或公开 API 触发的执行入口。
- **待授权执行**：不是代码缺口；必须另行确认生产备份、回退、窗口或具体远端业务操作后才能执行。

## 结论

ERP 本地业务、历史数据、高保真页面、统一身份/账号和旧域名入口已经完成生产迁移与融合。
唯一未激活的是需要额外业务授权的远端连接检测、标签同步及兑换码远端写操作；它们属于
“代码就绪/执行禁用”，不能因本次生产切换自动启用。
